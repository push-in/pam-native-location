# Changelog

## 0.1.1 - 2026-11-17

- Android 7.0/7.1 support: the plugin declares minSdk 24 and every newer Android API it uses has a version check and fallback. Requires PAM Native 1.53.1 or later.

## 0.1.0 - 2026-10-28

- First release: moved out of the PAM Native core (1.46) with the same native module name and wire payloads. Kotlin/JVM and PHP contract tests come from the core.
